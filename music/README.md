# music/

Drop one or more royalty-free relaxing **instrumental** tracks here (`.mp3`, `.m4a`, or `.wav`).

The pipeline picks one at random per video and loops it under the narration (ducked to ~15% volume so the voice stays clear).

## Where to get free tracks

These sources are free for commercial use and YouTube:

- **Pixabay Music** — https://pixabay.com/music/  (search "relaxing instrumental", filter by license: free)
- **YouTube Audio Library** — https://www.youtube.com/audiolibrary  (filter: no copyright)
- **Free Music Archive** — https://freemusicarchive.org/  (filter: CC0 / CC-BY)

`./run` will fetch a small starter pack from Pixabay on first setup, so you can be up and running without grabbing your own music first.

If you want to keep things simple: drop 3–5 long instrumental tracks here. The pipeline picks one per render.
