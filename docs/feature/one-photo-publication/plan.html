Implementation Plan

Scope

  • Add a non-rendered story-bible schema for in/ep0.json.
  • Skip ep0.json during automatic render input discovery.
  • Group source episodes into publication videos of up to 10 episodes.
  • Update docs, template, and authoring skill to require one image per source episode.
  • Document the grouped clip flow: welcome with channel image, spoken episode title, then episode image with narration for each source episode.
  • Document that the shared poster is for YouTube posting/thumbnail use and does not replace per-episode in-video images.

Risks

  • The pipeline cannot directly call the conversation ImageGen tool; image generation remains a Codex-assisted workflow that writes files into library/visuals/backgrounds/.
  • Legacy multi-chapter source episodes can still render, but publication grouping flattens them under the first episode image to enforce one image per source episode.
  • If the implementation does not yet synthesize per-episode title narration inside grouped videos, the docs mark that as required behavior for the next code update.

Verification

Run schema validation, story-bible validation, and the Python test suite.
