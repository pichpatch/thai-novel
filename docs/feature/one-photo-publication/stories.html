User Stories

  1. As the channel owner, I want ep0.json to store the whole story and prompts so every AI agent understands the same plan.
  2. As the channel owner, I want ep0.json to include open_ai_instruction so Codex can pre-generate the poster and episode images into the exact paths before rendering.
  3. As the channel owner, I want one image per episode so visual production is faster and more consistent.
  4. As the channel owner, I want each episode image to summarize that episode like a series ad poster as clean visual art with exactly one readable title set and no duplicate title layer, logo, signature, random text, or watermark.
  5. As the channel owner, I want up to 10 episodes in one MP4 so uploads can be packaged as longer compilation videos.
  6. As the channel owner, I want the grouped description to include every episode's short description so I can paste it into YouTube.
  7. As the channel owner, I want the grouped description to include a character relationship tree from those 10 episodes so viewers can understand the current character web.
  8. As the channel owner, I want the same story poster reused for every post while the video itself changes image at each episode boundary.
  9. As the channel owner, I want each episode in a grouped video introduced by spoken text: เรื่อง {story_name} ตอนที่ N {ep_title}.

Acceptance Criteria

  • ./novel validate ep0 validates the story bible.
  • ep0.json includes open_ai_instruction.poster.output_path and open_ai_instruction.episode_images[] with output paths, library refs, and prompts.
  • ./generate skips ep0.json.
  • Multiple active epNN.json files are chunked into groups of 10 by default.
  • ./generate --group-size 1 preserves one-video-per-source-episode behavior.
  • A grouped video starts with the channel image and welcome narration: ยินดีต้อนรับเข้าสู่ช่อง T H A I Novel ขอให้สนุกกับการรับฟังครับ.
  • The channel name in templates and generated episodes is T H A I Novel.
  • For each included episode, the clip speaks the episode title line, then shows that episode image while reading narration.
  • description.txt includes a relationship tree section when source episodes provide project.description_context.
  • The relationship tree covers prior state, current changes, latest status, and small details for characters appearing in the grouped video.

Onboarding Notes

The simplest mental model is: ep0 plans the series, epNN tells one source episode, and grouped render publishes up to 10 source episodes together.
